## 1. Objetivo do capítulo

Registrar como a aplicação deve se comportar para o usuário antes da implementação: telas, fluxo de uso e protótipos.

## 2. Fluxo de uso

1. O usuário importa uma planilha Excel ou CSV.
2. A normalização mapeia as colunas, padroniza os formatos e valida os dados.
3. Os lançamentos são guardados no histórico local.
4. A classificação financeira atribui receita/despesa e categoria a cada lançamento.
5. A previsão financeira estima receitas e despesas futuras.
6. O dashboard mostra os resultados em gráficos.
7. O usuário exporta os resultados para Excel ou CSV.

## 3. Telas previstas

| Tela | Função |
|---|---|
| Importação | Enviar o arquivo Excel/CSV e conferir o mapeamento das colunas |
| Classificação | Ver as categorias atribuídas aos lançamentos |
| Previsão | Ver o fluxo de caixa previsto |
| Dashboard | Gráficos de receitas, despesas e fluxo de caixa |
| Exportação | Baixar os resultados em Excel/CSV |
